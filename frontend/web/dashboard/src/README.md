# Source layout

Architecture rules for the dashboard. All imports use the `@/` alias; never `./` or `../`.

| Folder | Rule |
| --- | --- |
| `interfaces/` | One interface per file, `<name>.interface.ts`. |
| `types/` | One type per file, `<name>.type.ts`. |
| `schemas/` | One Zod schema per file, `<name>.zod.ts`. |
| `enums/` | Explicit TypeScript enums for domain modes and categories. |
| `components/` | No flat files. Group into typed subfolders (`buttons/`, `forms/`, `dialogs/`, `layout/`, shadcn `ui/`). |
| `services/api/query/` | Read-only API actions (TanStack Query). |
| `services/api/mutation/` | Write API actions (TanStack mutations). |
| `store/` | Zustand client state (theme, auth profile). Layout state that needs server seeding lives in providers instead. |
| `components/providers/` | App-wide and portal context providers (`SidebarProvider`, `I18nProvider`, `AppProviders`). |
| `components/overlays/` | `OverlayProvider` and the single dialog/sheet host. Add a kind to `OverlayKind` and `OverlayRequest`, then a case in `OverlayHost`. |
| `lib/` | Shared helpers (`utils.ts` is generated by shadcn). |
| `config/` | `*.constant.ts` files: actors, routes, cookies, nav, locales. |
| `locales/` | Typed EN and AR dictionaries, split by namespace, plus locale resolution. |
| `hooks/` | One hook per file, named `use-<name>.ts`. |
| `tests/` (project root) | Mirrors `src/`; import app code and helpers through `@/` and `@tests/`. |

## Routing

Paths are guard-segmented: `host/dashboard/<guardName>/...`, which maps to
`src/app/dashboard/[guard]/...`.

- `login/` is public. `(portal)/` is the signed-in shell and reads the session behind Suspense.
- `app/api/auth/*` (session) and `app/api/dashboard/[...path]` (the allow-listed data forwarder) are the only route handlers that talk to the backend.
- Guard names come from `AUTH_ACTORS` in `config/auth-actors.constant.ts`; never keep a second list.
