# Dorak Backend (دورك)

The Laravel 13 API behind the Dorak salon and barber platform: a modular monolith on PHP 8.3+ and MySQL, with all
application code under `modules/`. `Modules\Core` supplies configuration, shared HTTP classes and CQRS primitives.

- Setup, tests and quality checks: [repository README](../README.md#local-setup).
- Architecture, conventions and gates: [backend guide](AGENTS.md).
- What the API does: [feature index](docs/feature-index.md). Product documents: [docs](docs/README.md).
- Deployment: [deployment guide](../docs/deployment/deployment-guide.md).
