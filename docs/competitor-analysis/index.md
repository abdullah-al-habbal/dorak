# Competitor analysis

Routes: [documentation graph](../index.md) · [README](../../README.md) · [backlog](../backlog/index.md)

This folder holds outside-in studies of products that compete with Dorak Operations or serve the same salon and barber market. Each competitor has its own folder with an index and one file per topic, so a study can be read in full or one topic at a time.

A study is built from public sources (store listings, official sites, public registries) and a sample of the public experience. It records what is established, what is only announced, and what cannot be verified, so a figure is never presented as stronger than its source. Conclusions are analytical judgments and feed product decisions; they are not requirements. When a finding turns into work, record it in the [backlog](../backlog/index.md).

To add a competitor, create `docs/competitor-analysis/<name>/` with its own `index.md`, one file per topic, and a row in the table above. Keep sources linked inline, and keep the language of the folder consistent with the rest of `docs/` (English), and keep competitor studies free of Dorak conclusions until the comparison stage. Research about Dorak itself lives in [product research](../product-research/index.md), not here.
